◆ ShadowForge Validator NFT Mint

This mints the real, free, one-per-wallet soulbound validator NFT (spec 10.1) — the credential a wallet needs before a node running as that identity can heartbeat, join a committee, or vote (spec 4.5/10.1/243). It is a functional access credential, not artwork: there is no image attached to it. Every step below calls this page's own server, which performs the exact same real signing and submission wallet identity / wallet poh-attest / wallet nft-mint do from the command line — nothing here is simulated.

1. Your identity

The address that ends up owning the NFT must be the same identity your validator node runs as (its -key-file). Generate a fresh one here and you'll get both a wallet keystore and a matching node identity file in one step — or load an existing keystore below if you already have one.

2. Proof-of-humanity attestation

A trusted attestor signs a real, time-limited claim that this address passed a real proof-of-humanity check (spec 10.1 — that check itself happens by whatever real means the attestor uses; this page never decides it). Pick a nonce for this mint attempt (any number you haven't used before for this identity works — the default is fine), then either run the attestor panel below yourself, or send your address + nonce to whoever runs it and paste back what they give you.

Attestor panel (run this if you are the attestor)

3. Mint

Submits the real, signed mint transaction to a live node and waits for it to confirm committed — the same broadcast-and-confirm path wallet nft-mint uses.

Every field on this page is submitted to this page's own server and processed with the real pkg/walletkey / pkg/nft / pkg/txbuilder / pkg/txclient packages (cmd/mintpage) — the same code wallet identity, wallet poh-attest, and wallet nft-mint run from a terminal. Passphrases are never written to disk unencrypted and never logged. Keep this page on loopback / behind your own TLS unless you know what you're doing.
